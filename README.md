#Student Teacher Appointment Booking


## **Project Overview**

The **Student Management System with Teacher Interaction** is a web-based platform designed to streamline the communication between students and teachers in educational institutions. The system provides a centralized solution for student registration, teacher search, appointment scheduling, and messaging, enhancing the overall academic experience.

Built using **HTML, CSS, JavaScript**, and powered by **Firebase** for user authentication, real-time data synchronization, and storage, the system is both efficient and secure. Students can easily register, book appointments, and send messages to teachers, while teachers can manage appointments, approve or cancel requests, and respond to student queries. 

## **Features**

- **User Authentication:**
  - Secure student and teacher registration and login using Firebase Authentication.
  
- **Student Dashboard:**
  - Register and login to the system.
  - Search for teachers based on subject or department.
  - Book appointments with teachers based on availability.
  - Send and receive messages from teachers.

- **Teacher Dashboard:**
  - Manage and approve student appointment requests.
  - View scheduled appointments and communicate with students.

- **Admin Features (Optional):**
  - Manage user accounts, monitor appointments, and oversee messages exchanged between students and teachers.

- **Real-Time Data:**
  - Firebase Firestore allows real-time synchronization for appointments, messages, and updates across the platform.

- **Responsive Design:**
  - The platform is fully responsive and designed to work seamlessly across devices such as desktop, tablets, and mobile phones.

## **Technologies Used**

- **Frontend:**
  - HTML
  - CSS
  - JavaScript
  - Firebase SDK (for Authentication and Firestore)

- **Backend:**
  - Firebase Firestore (Real-time database)
  - Firebase Authentication (User login and registration)

- **Others:**
  - Responsive Web Design (using CSS media queries)
  - Firebase Hosting (for deploying the application)


## **Usage**

1. **Student View:**
   - Students can create an account or log in, search for teachers, book appointments, and send messages.

2. **Teacher View:**
   - Teachers can manage appointments and respond to messages from students.

3. **Admin View :**
   - Admins can manage users, monitor system activities, and oversee student-teacher interactions.
